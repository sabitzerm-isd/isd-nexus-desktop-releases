# ISD Nexus Desktop – Installer und Updates

Dieses Repository enthält **ausschließlich** die signierten Installer von ISD Nexus Desktop:

- `ISD Nexus Desktop_<Version>_x64-setup.exe` – Installer für Windows (für den eigenen Benutzer, ohne Administratorrechte)
- `….exe.sig` – Signatur des Installers (prüft die automatische Aktualisierung)
- `latest.json` – Angaben zur neuesten Version für die automatische Aktualisierung

Der Quellcode liegt nicht hier.

**Neueste Version herunterladen:** [Releases → Latest](https://github.com/sabitzerm-isd/isd-nexus-desktop-releases/releases/latest)

Ein installiertes ISD Nexus Desktop findet neue Versionen selbst und bietet sie zur Aktualisierung an.
Installiert werden nur Updates, deren Signatur zum im Programm hinterlegten Schlüssel passt.
